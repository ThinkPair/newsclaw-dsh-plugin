# DSH 设置页真实契约

## 原则

DSH 是新闻爪的一个客户端，不是第二个配置中心。后端业务配置只有一份，以新闻爪电脑版和专用新闻接口返回的 `effective_settings` 为准。

## 读取接口

| 页面 | 接口 | 展示内容 | 是否可编辑 |
|---|---|---|---|
| 运行状态 | `GET /api/news/runtime` | 在线/降级/离线、最近刷新、入池数量、调度通道、画像状态、生效刷新参数 | 否 |
| 新闻来源 | `GET /api/news/sources` | 媒体、技术提供方、启用状态、健康状态、最后成功、错误 | 否 |
| 插件连接 | Harness 插件行 | `apiUrl`、`timeoutMs` | DSH 配置文件中修改 |
| 本机启动 | `GET /api/autostart-status` | 当前开机自启动状态 | 是，经专用接口 |

## 不在 DSH 编辑的项目

- AI v2 实例、默认链与各模块路由
- DeepSeek、Tushare 等凭据
- 新闻源开关、自定义 RSS
- 候选池、热门/探索刷新、反馈阈值、后台 AI、浏览器关闭行为和重试策略
- 推荐、画像、存储和日志配置

这些项目统一在 `http://127.0.0.1:8430/web` 的电脑版设置中维护。DSH 设置页只显示后端确认已经生效的结果。

## 连接的一致性

Harness 用同一行配置同时加载插件的 Node 端和浏览器端。浏览器端从该行解析 `apiUrl` 与 `timeoutMs`，并把 `apiUrl` 镜像到本地兼容存储；右侧栏与 31 个 Agent Bridge 工具因而默认指向同一个后端。更改插件行后需要重新加载插件。

`timeoutMs` 只代表 Agent Bridge 命令的单次总预算；右侧栏的轻量状态请求有各自较短的网络超时。
